## P0：审计评测脚本 ✅ 已完成

结果见 [memory-p0-audit.md](memory-p0-audit.md)。发现的 3 个问题：

1. 非循环臂上 `independent`/`reset`/`carried` 是**同一段代码** → 25 个格子不含证据；

**因此唯一干净的对照是循环臂上的 `carried − reset`。**

### （以下为原始设计说明，保留备查）

### 1.1 为什么不能直接用 SciFact

上一版方案写「查询用原 SciFact 查询，正例用相关文档的最后一块，前面块提供消歧上下文」。
**该设计有致命风险**：如果最后一块自身已含足够判别信息，
模型**不使用跨块记忆也能完成任务**，实验再次无效。

SciFact 摘要短、块间依赖弱，无法保证"必须跨块"。

### 1.2 最小合成任务（推荐先做）

**目标不是让任务变难，而是确保我们知道模型为什么答对。**

#### 任务定义

必须**结合两块信息**才能作答：

```
块 A（实体 → 属性）：
  项目 ORION 使用蓝色密钥。项目 VEGA 使用红色密钥。

块 B（实体 → 当前目标）：
  本次需要检查的是项目 VEGA。

查询：本次应该使用什么颜色的密钥？
正确：红色
```

- 只看 A：不知道要查哪个项目 → 无法作答；
- 只看 B：不知道颜色 → 无法作答；
- **只有保留 A 的信息并在读到 B 后组合，才能答对。**

#### 必须满足的构造要求

| 要求 | 实现方式 | 为什么必须 |
|---|---|---|
| 实体随机化 | 实体名从大词表随机采样 | 防止模型记住固定实体 |
| 顺序变化 | A/B 块顺序随机（含 B 在前的情况） | 防止靠位置猜 |
| 干扰项 | A 中放 4–8 个其他实体-属性对 | 迫使真正检索而非平均 |
| 无记忆对照 | 基线必须**无法**答对 | 这是任务成立的核心判据 |
| 测试集隔离 | 测试用训练**未出现**的实体组合与模板 | 防止模板记忆 |
| 反捷径检查 | 报告 `chunk_overlap_ceiling` 与 `lexical_leakage` | 上一轮教训：conflict 词面上限 = 1.00 |

#### 成立判据（P1 的验收标准）

在**投入 350M 训练之前**，必须先用简单基线确认：

| 检查 | 期望 | 若不满足 |
|---|---|---|
| 随机基线 | ≈ 1/候选数 | 任务或评分有 bug |
| 词面上限 `chunk_overlap_ceiling` | **显著低于 1.0** | 任务可被词面捷径解决，重做 |
| 无状态模型（B0/B3）的 `carried` | **≈ 随机** | 任务不需要记忆，重做 |
| 真·状态模型（若机制成立） | **> 随机** | 见下 |

**关键**：前三项必须全部满足，任务才算"成立"。
第四项（真·状态模型是否 > 随机）是 P2 的问题，不是 P1 的验收条件。

#### 先用小模型验证可学习性

在动 350M 之前，用**小型模型**（如 2 层、hidden 128）跑合成任务，
确认：任务可学习 + 基线确实做不到。这能在几分钟内排除任务设计错误。

### 1.3 P1 的产出

1. `scripts/make_synthetic_crossblock.py` —— 数据生成器（含实体随机化与模板隔离）；
2. 基线评估结果（随机、词面、B0/B3 的 `carried`）；
3. **一个明确判断**：任务是否成立。若不成立，改任务而不是改模型。

## P2：统一训练条件，做目标函数实验

> **已执行首轮，结论见 [memory-p2-summary.md](memory-p2-summary.md)。**
>
> 关键结果：
> - v1 任务（块 B 直接写实体名）**训练目标有词面捷径**：loss 3.65→1.27，
>   但测试仍随机。学到的是"匹配实体名"，不是"查颜色"。
> - v2 任务（memo→entity→colour 链）**信号干净**（oracle 1.000，假负例率 ~5/6000），
>   但 **loss 学不动**（15 epoch 仅 4.87→4.60），所有策略 ≈ 随机。
> - `--easy` 降难度变体**不可用**：词面上限从 0.075 升到 0.263，任务退化成可捷径解。
> - n=300 时曾出现 `carried`(0.170) > `reset`(0.120) 的"正信号"，
>   **扩到 n=1500 后塌缩为 +0.002**，确认为抽样噪声。
>
> **因此在建立"可学习的跨块任务"之前，P2 无法评判记忆机制。**

### 2.1 前置修正（来自 P0）

1. `independent` 改为**逐块串行、不传状态**，与 `carried` 批处理对齐；
2. 统一批量（96+1），复跑 B5 使其与 B5r/B6/B6r 可比；
3. 报告表格区分「有效格子」与「恒等式格子」。

### 2.2 实验矩阵

| 条件 | 说明 |
|---|---|
| 无状态基线 | `independent`（逐块串行，不传状态） |
| 状态重置 | `reset` |
| 状态传递 | `carried` |

### 2.3 判据

```
成功：carried > reset  且  carried > independent，且稳定超种子噪声
```

- 先跑 **1 个种子**确认方向；
- 方向正确且幅度明显 → 扩到 **≥3 个种子**；
- 方向为 0 或负 → **不要加预算**，回到 P1 检查任务或转去改结构。

**每臂至少 3 个种子是最终报告的最低要求**（本轮只有 1 个种子，是主要缺陷）。

## P1.5（新增，当前最高优先级）：找到"可学习的跨块任务"

P2 证明了一件事：**任务可以做到"必须跨块"，但这样的任务当前模型学不动。**
这是下一轮真正要解决的问题，且**必须在不牺牲判别性的前提下**解决。

### 为什么两条现有路线都不通

| 尝试 | 结果 | 原因 |
|---|---|---|
| v1（块 B 写实体名，正例整块 A） | 可学（loss→1.27）但学到错的东西 | 训练目标有词面捷径 |
| v2（memo 链，正例唯一） | 信号干净但学不动（loss→4.60） | 要求符号级三跳，超出编码器能力 |
| easy 变体（2 对、4 候选） | 可学性未验证 | 词面上限 0.263，退化成可捷径解 |

**"降难度"与"必须跨块"直接冲突**，不能靠调参数解决。

### 建议的三条新方向

1. **用"软"语义依赖替代符号查表**
   不做 memo 编号→实体的精确绑定，而用**自然语用依赖**：
   ```
   块 A："The Meridian protocol requires rotating credentials every 30 days."
   块 B："For the audit we follow the stricter of the two schedules."
   ```
   正确答案需要理解"stricter"指哪个——这是语义推理，不是符号查找。
   代价：须用 `chunk_overlap_ceiling` 严格验证无捷径。

2. **两阶段训练**
   先在简单版（v2 easy）上训练到 `concat` 超过随机，
   再逐步提高难度（课程学习）。关键：**每提一档都要重测词面上限**。

3. **换更合适的基础模型做机制验证**
   在小型模型（2 层、hidden 128）上从头训练该任务。
   若能学会，说明任务可学习、350M 的预训练表征反而是障碍（需要更多适配）；
   若小模型也学不会，说明任务设计本身有问题。
   **成本低（几分钟），信息量大，建议先做。**

### 验收线（不可妥协）

| 检查 | 阈值 |
|---|---|
| `chunk_overlap_ceiling` | ≤ 0.25 |
| `lexical_leakage` | ≤ 0.10 |
| oracle 可推导率 | ≥ 0.99 |
| **`concat` 在测试集** | **≥ 随机 + 0.10**（任务可学习的证据） |
| 样本量 | ≥ 1500（防止小样本假信号） |

**只有全部满足，才允许用 `carried − reset` 评判记忆机制。**

## 附录：为什么"负面结果 ≠ 路线失败"

本轮的一个有价值副产品是排除了一类陷阱：

> **不能因为有记忆槽、循环状态、门控，就认定模型学会了记忆。**
> **同样，不能因为当前状态传递有害，就认定这条路线没有未来。**

有价值的证据应当同时满足：

1. 任务确实需要跨块信息；
2. 无记忆基线无法通过捷径解决；
3. `carried` 稳定优于 `reset` 和 `independent`；
4. 优势在多个种子、不同数据构造、合理容量对照下仍存在；
5. 优势不只体现在合成任务上，还能在真实长文档任务中复现。

**第五条之前的任何一条不成立，都不能声称"学到了有用的跨输入记忆机制"。**

## 风险清单

1. 合成任务可能"过于人为"，学到的机制无法迁移（→ P3 的意义）；
2. 单轮 1 epoch 可能不足，需与"训练更久"的对照区分；
3. 小模型可学习 ≠ 350M 可学习，但小模型**不可**学习几乎必然意味着任务有问题；
4. **本文档所有数字均为设计参数，不是测量值。**

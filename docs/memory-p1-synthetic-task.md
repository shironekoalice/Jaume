# P1 合成跨块任务：成立性验证结果

> 日期：2026-10-17
> 数据生成：`scripts/make_synthetic_crossblock.py`
> 验收脚本：`scripts/p1_acceptance.py`
> 数据：`data/synth_crossblock/{train,dev,test}.jsonl`
> **本文档只做任务成立性验证，未训练任何模型。**

## 1. 任务定义

必须**结合两块信息**才能作答：

```
块 A（实体 → 属性）：
  ORION 使用 blue 密钥。VEGA 使用 red 密钥。（+ 4–8 个其他实体-属性对）
块 B（实体 → 本次目标）：
  本次需要检查的是 VEGA。
查询：应该使用什么颜色的密钥？
正确：red
```

- 只看 A：不知道要查哪个项目 → 不可答；
- 只看 B：不知道颜色 → 不可答；
- 只有保留 A 的信息并与 B 组合，答案才被确定。

## 2. 反捷径措施（逐项对应上一轮的失败教训）

| 措施 | 上一轮对应教训 |
|---|---|
| 实体名从生成词表采样 | 固定实体会被记住 |
| 属性独立随机 | 属性与实体不能有固定关联 |
| **块顺序逐条打乱** | 防位置猜测 |
| 块 A 内放 4–8 个干扰对 | 防平均池化直接命中 |
| 查询不含实体名与颜色 | 防查询-候选词面重叠 |
| 候选只是颜色词 | 候选不含实体名 |
| **train/dev/test 实体池与模板均不相交** | 防模板记忆 |

## 3. 成立性检查（P1 验收标准）

| 划分 | n | 平均候选数 | 随机基线 | 词面泄漏 | **词面上限** | **单块上限** | 判定 |
|---|---|---|---|---|---|---|---|
| train | 600 | 6.8 | 0.152 | **0.000** | **0.055** | 0.065 | ✅ PASS |
| dev | 150 | 6.7 | 0.156 | **0.000** | **0.080** | 0.080 | ✅ PASS |
| test | 150 | 6.7 | 0.156 | **0.000** | **0.080** | 0.080 | ✅ PASS |

**对比上一轮 conflict 探针：词面上限 = 1.00（完全不读记忆即可满分）。**
本任务的词面上限 **0.055–0.080，远低于随机基线 0.152**——
说明词面匹配与单块信息不仅无助于解题，反而是**负信息**（因为正确颜色在块 A 中是随机位置）。
这正是"必须跨块"的量化证据。

阈值：`词面泄漏 ≤ 0.10`、`词面上限 ≤ 0.25`、`单块上限 ≤ 0.25` → 全部满足。

## 4. 模型验收：现有权重能否解题

在 test 划分（150 条，随机 0.156）上，用 `memory_only` 评分：

| 臂 | 循环? | independent | reset | carried | concat | query_only |
|---|---|---|---|---|---|---|
| B0-mean | 否 | 0.213 | 0.213 | 0.213 | 0.227 | 0.187 |
| B3-latent | 否 | 0.167 | 0.167 | 0.167 | 0.160 | 0.120 |
| B5-recurrent | **是** | 0.167 | 0.127 | **0.147** | 0.160 | 0.120 |
| B6-recurrent-gate | **是** | 0.160 | 0.147 | **0.147** | 0.160 | 0.167 |

### 4.1 三个观察

1. **所有臂、所有策略都在随机水平**（0.120–0.227，随机 0.156）。
   没有任何模型学会这个任务——这是预期结果，因为现有权重从未见过该任务形式。

2. **B0/B3 的 `reset` 与 `carried` 仍然完全相等**，
   与 P0 审计（非循环臂上三者是同一段代码）一致，**再次确认审计结论**。

3. **循环臂上第一次出现非负的 `carried − reset`**：
   - B5：0.147 − 0.127 = **+0.020**
   - B6：0.147 − 0.147 = **0.000**

## 5. 对 +0.020 的严格解读（不可高估）

**该差异不能作为证据**，理由：

- n=150 → 单条样本代表 0.0067，+0.020 ≈ **3 条样本**；
- 未跑多种子，无法与种子噪声区分；
- 上一轮 JM-S 阶段的经验是种子间 σ≈0.004–0.007（那是 STS 指标，探针指标的方差更大）。

**唯一可以说的**：在这个**唯一干净的探针**上，`carried − reset` **不再是负数**。
这与上一轮（唯一干净探针 aggregation 上 −0.867 的崩溃）形成对比，
但**远不足以主张记忆有效**。

## 6. P1 结论

### 6.0 Oracle 检查（答案是否真的可推导）

任务"必须跨块"还不够——还要确认**答案确实能从两块推导出来**，
否则是构造 bug，任何模型都学不会，训练就是白跑。

用正则解析器（读两块、找块 B 的目标实体、在块 A 中查其颜色）：

| 指标 | 结果 |
|---|---|
| 样本数 | 150 |
| **可推导率** | **1.000**（150/150） |
| 解析失败 | 0.000 |
| 答案不符 | 0.000 |

**PASS**：答案 100% 由两块信息唯一确定，任务在原理上可学习。

### 6.1 综合判断

| 问题 | 答案 |
|---|---|
| 任务是否真的需要跨块信息？ | ✅ **是**（词面上限 0.08 < 随机 0.156） |
| 答案是否可推导？ | ✅ **是**（oracle 1.000） |
| 无记忆基线能否走捷径？ | ✅ **不能**（0.167–0.213 ≈ 随机） |
| 现有权重能否解决？ | ❌ **不能**，所有臂 ≈ 随机 |
| 是否值得投入训练？ | ✅ **值得**——任务问对了问题，答案可推导，且现有权重从未见过它 |

**因此 P2（统一条件 + 目标函数实验）现在有依据，而不是盲跑。**

## 7. 诚实标注的不确定性

1. **任务"成立"不等于"可学习"**：目前无任何模型解出，
   所以还不知道 350M 能否学会。P2 的第一个实验就是回答这个。
2. 合成任务可能过于人为，学到的机制未必迁移（→ P3 的意义）。
3. 候选平均 6.65 个、随机 0.156，样本量 150 时 **0.156 与 0.213 的差异
   （B0）不足以宣称 B0 强于随机**——B0 的 0.213 也可能只是噪声，
   **不应解读为"B0 部分会做"**。

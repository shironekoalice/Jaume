# P2 合并结论：实验台的两次迭代与最终状态

> 日期：2026-10-17
> 本文合并 [memory-p2-round1.md](memory-p2-round1.md) 与 v2 迭代结果。
> **核心结论：JM-R 的判定仍为"未通过"，但真正的产出是
> 我们现在知道*为什么*之前的实验无法判定。**

## 1. 做了什么

| 步骤 | 内容 | 结果 |
|---|---|---|
| P0 | 审计评测脚本 | 发现 3 个缺陷（含 1 个使部分结论失效） |
| P1 | 建立合成跨块任务 v1 | 任务成立（词面上限 0.08），但训练目标有词面捷径 |
| P2 v1 | 在 v1 上训练 B5/B6（1 与 5 epoch） | loss 3.65→1.27，测试仍随机 |
| P2 v2 | 修掉训练捷径（memo→entity→colour 链） | oracle 1.000，但 loss 不降（4.87→4.72），测试仍随机 |

## 2. 三个版本的实验台，各自的缺陷

### v1（块 B 直接写实体名）

```
块 B：The one to inspect is project VEGA.
块 A：VEGA 使用 red 密钥。ORION 使用 blue 密钥。……
正例：整块 A
```

**缺陷**：块 A 里印着 `VEGA`，查询里也有 `VEGA`。
模型只要匹配实体名就能降低对比损失 → 训练 loss 降到 1.27，
测试仍随机（0.146–0.156 vs 随机 0.152）。
**学到的能力（匹配实体名）无法转化为选出颜色。**

### v2（memo 链，正例唯一化）

```
块 B：The item under review is the asset in memo 105.
块 A：……PIERADO 使用 blue 密钥。Filed under memo 105.……
正例：pierado blue
```

**改进**：查询只含 memo 编号，块 A 不含块 B 的词面，
正例唯一（6000 条中 4189 个唯一，最大重复 5 次，
假负例率从 ~500 降到 ~5）。

**结果**：oracle 1500/1500 = 1.000（链路完全可推导），
但 **loss 几乎不降（4.87 → 4.72）**，测试 0.137–0.143 vs 随机 0.151。

## 3. 为什么 v2 学不动（诚实的分析）

v2 要求模型完成一条**符号级链路**：

```
memo 105  →  在某块中找到 memo 105  →  读出该条目的实体 PIERADO
          →  读出 PIERADO 的颜色 blue  →  与候选 "Blue" 匹配
```

难点：

1. 块 A 含 5–9 个「实体 + 颜色 + memo」三元组，需要**精确的符号绑定**，
   不是模糊语义相似度；
2. 块被截断到 128 token，长块可能丢失部分条目；
3. 350M 编码器在 NLI 相似度上预训练，从未做过这种"编号查表"任务；
4. 单块上下文内就要完成三跳推理，跨块还要再组合。

**这不是记忆机制的问题，是任务难度曲线跳得太陡。**

## 4. 当前的判定（严格表述）

| 主张 | 判定 | 依据 |
|---|---|---|
| JM-R 在预注册标准下通过 | ❌ **未通过** | 见 [memory-results-crossinput.md](memory-results-crossinput.md) |
| 跨输入状态带来可靠收益 | ❌ **无证据** | 48 格中 43 零 / 4 负 / 1 正 |
| 现有评测探针有效 | ❌ **6 个中 4 个无效** | 词面上限 0.63–1.00 |
| "记忆机制失败" | ⚠️ **不能断言** | 未建立可学习的跨块实验台 |
| 建立了经过验证的实验台 | ⚠️ **部分** | v2 任务干净但学不动 |

### 4.1 一次差点被误报的"正信号"（重要教训）

v2 任务训练 15 epoch（loss 4.87→4.60，930 步几乎学不动）后，
先在小样本上评测：

| n | carried | reset | 差值 | 表面结论 |
|---|---|---|---|---|
| **300** | **0.170** | 0.120 | **+0.050** | "首次出现 carried 同时超过 reset 和 concat" |
| **1500** | **0.153** | 0.151 | **+0.002** | **信号消失**（≈3 条样本） |

n=300 时看起来是整个 JM-R 研究里**第一次**出现 `carried` 同时超过
`reset`(0.120) 和 `concat`(0.113) 的结果。
扩大样本量到 1500 后，差值从 +0.050 塌缩到 **+0.002**。

**若停在小样本结果，就会得出一份"JM-R 首次出现正收益"的错误结论。**

最终：所有策略 0.145–0.153，随机 0.151，全部在随机水平。

**教训**：探针 n=300 时单条样本代表 0.0033，但策略间差异的标准误约 0.02，
+0.050 处在 2σ 边缘、极易由抽样波动产生。
**任何"首次出现正收益"都必须用至少 1500 条复核。**

## 5. 下一步（明确、可执行）

**停止在同一处继续调参。** 解决路径是把难度拆开，二选一：

### 路线 A：降低任务难度，确保 `concat` 先学会

目标：先让**无记忆的 `concat` 策略**显著超过随机。
这是"任务可学习"的最直接判据，且与记忆无关。

**⚠️ 已尝试并失败（`--easy` 变体）**：

把块 A 降到 2 个实体-颜色对、候选降到 4 个后，
词面上限从 0.075 **升到 0.263**，超过 0.25 的合格线：

| 划分 | 原版 chunk_ceil | easy 版 chunk_ceil |
|---|---|---|
| train | 0.075 | 0.248 |
| dev | 0.073 | **0.253** ❌ |
| test | 0.068 | **0.263** ❌ |

**原因**：只放 2 个实体-颜色对时，正确颜色在块 A 中出现的概率降到约 50%，
词面匹配的相对判别力反而上升。

**结论：降难度与"必须跨块"直接冲突，不能靠这条路线。**
不应为了让模型学会而牺牲任务的判别性——那会退化成上一轮
"conflict 探针词面上限 1.00" 的同类错误。

因此**路线 A 作废**，直接走路线 B。

### 路线 B：换成"自然长文档"任务

放弃符号查表，改用真正的长文档压缩：
- `data/mlm_corpus.jsonl`（455MB）按 256 token 切块；
- 目标：预测下一块的首句 / 检索被遮蔽块。

优点：不要求符号绑定；缺点：自监督目标与检索目标不完全一致。

**建议先做路线 A**，成本低、判定清晰。

## 6. 本轮的方法学教训（值得记住）

1. **"任务必须跨块"和"训练信号必须干净"是两件事。**
   前者靠词面上限检查，后者要靠 oracle 检查 + 假负例率检查。
2. **loss 下降不代表学到了想学的东西。**
   v1 的 loss 从 3.65 降到 1.27，但学的是词面匹配。
   必须看**测试集的策略间差异**，不能只看训练 loss。
3. **不要在没有"任务可学习"证据时评判机制。**
   否则每一轮都会得到"记忆无效"的结论，而实际上模型连任务都没学会。
4. **`carried − reset` 只有在 `concat` 明显超过随机时才有意义。**
5. **小样本的正信号必须用大样本复核。** n=300 的 +0.050 在 n=1500 塌缩为 +0.002。

## 8. 小模型对照实验（已执行）

为区分"任务不可学"与"预训练表征是障碍"，用**从头训练的小模型**
（embedding + mean pooling + 单层线性，dim 128，vocab 2460）在同一 v2 任务上训练 30 epoch：

```
epoch  0  loss 10.0453
epoch 10  loss  6.8858
epoch 20  loss  5.9755
epoch 29  loss  5.4783

test n=1500  chance=0.151  acc=0.107
```

**结果：loss 缓慢下降，但测试 0.107 < 随机 0.151。**

### 8.1 解读（必须带不确定性）

| 观察 | 含义 |
|---|---|
| loss 从 10.05 降到 5.48 | 模型在拟合**某种**训练信号 |
| 测试低于随机（0.107 < 0.151） | 学到的东西**不迁移**，甚至有害 |
| 350M 预训练模型同样学不动 | 两个架构都失败 |

**谨慎表述**：这个小模型（mean pooling、无注意力、无位置编码）本身能力很弱，
它学不会是**弱证据**——不能据此断定"任务不可学"。

但结合 350M 模型 15 epoch 也学不动（loss 4.87→4.60），
形成一个**一致的模式：任何模型都无法把 v2 任务学到超过随机**。

### 8.2 结论

v2 任务的**判别性完全可信**（词面上限 0.068、oracle 1.000、捷径已堵死），
但**可学习性未获证实**，两个独立实现都失败。

**在可学习性被证实之前，`carried − reset` 仍不能用于评判记忆机制。**
这不是记忆路线的失败，而是实验台尚未完成。

### 8.3 下一步（P1.5，最高优先级）

见 [memory-next-steps.md](memory-next-steps.md) 的 P1.5 节，三条方向。
**优先做"自然语用依赖"**（软的语义依赖而非符号查表），
因为 v2 失败的原因高度指向"符号级三跳超出编码器能力范围"。

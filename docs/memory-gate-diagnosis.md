## 0. 先修正上一轮的一个测量错误

### 真实代码路径（`jaume/modeling/memory.py`）

```python
def forward(self, hidden_states, attention_mask=None, memory_state=None):
    new_slots = self.core.slot_pass(hidden_states, attention_mask, memory_state)
    if memory_state is not None and self.use_gate:
        carry = self.gate(memory_state, new_slots)      # ← G2
    else:
        carry = new_slots
    pooled_from = carry if self.output == "carry" else new_slots
    return self.core.pool_slots(pooled_from), carry     # ← 返回的是 carry
```

**存在两层独立的 gate**：

| gate | 位置 | 输入维度 | 何时存在 |
|---|---|---|---|
| **G1** | `LatentMemoryPooling.slot_pass`（`state_update="bounded"`） | `[slots ; read]` 1024 | 仅 R1b 实验 |
| **G2** | `GatedSlotUpdate`（`RecurrentMemoryPooling.gate`） | `[prev_state ; new_slots]` 1024 | **B6 一直有** |

**上一轮 D1/D3 测的是 `slot_pass` 的输出，而真正返回并被传递的状态是 `carry`（G2 输出）。测错了对象。**

本轮 D8 专门验证这一点：

```
measured path vs real forward return: max |diff| = 0.000e+00   PASS
```

**本次测量路径与真实前向完全一致。**

## 3. 决定性对比：gate 在训练中退化了（**此结论已被 §3.2 推翻**）

直接测 `GatedSlotUpdate` 初始化时的行为（随机输入）：

| 状态 | g 均值 | **g 标准差** |
|---|---|---|
| **初始化**（随机输入） | 0.5031 | **0.1316** |
| **训练 1 epoch 后**（真实输入） | 0.5193 | **0.0063** |

**标准差缩小 21 倍。** 初始化参数：

```
weight mean|.| = 0.0156,  std = 0.0180
bias ≈ 0.01
```

权重极小 → logit 集中在 0 附近 → sigmoid(0)=0.5。

### 3.1 这改变了问题的性质

**不是"gate 结构无能力"，而是"训练把 gate 推成了常数"。**

初始化时 gate 的 sd 是 0.132，说明**它本来就能对不同输入给出不同响应**；
训练后降到 0.006，说明**优化过程主动选择了"不动"**。

### 3.2 权重检验：两次修正后才得到正确结论

**第一次修正（错误）**：比较 `mean|.|` 统计量，发现三个 checkpoint 都是 0.0156，
与初始化一致 → 错误地推断"gate 从未被训练"。

**`mean|.|` 不是可靠的比较量**——随机重初始化后该统计量也会接近。

**第二次检验（逐位对比）**：

| checkpoint | max\|w−w_init\| | **相对变化 \|Δw\|/\|w_init\|** |
|---|---|---|
| R1-smoke-additive | 0.0645 | **1.4144** |
| R1-smoke-norm | 0.0654 | **1.4159** |
| R1-smoke-bounded | 0.0649 | **1.4165** |

**权重被大幅更新（相对变化 141%）。**

### 3.3 正确的结论

```
gate 权重训练后变化 141%，但输出 g 的标准差只有 0.006（≈常数 0.52）
```

**即：gate 被训练了，而且训练出了一个"几乎不依赖输入"的解。**

权重虽大，但方向使 logits 高度集中在 0 附近 →
不同输入（哪怕槽状态差异明显）都映射到接近 sigmoid(0)=0.5 的值。

**这是真正的"学会忽略输入"，不是"没训练"。**

因此：

> gate 确实退化成了近似常数，且是**被训练成这样**的。
> 但下一个问题更重要：**为什么训练会认为"忽略记忆"是更优解？**

答案**尚未确定**。一个候选解释是"状态里没有可利用的信息"，
但更准确的表述是（采纳评审意见）：

> **在当前 checkpoint、当前训练阶段（仅 1 epoch）与当前评测设置下，
> 没有测出可重复的记忆收益。**

**这不等于"记忆对损失没有帮助"。** 1 轮训练不足以区分
"机制不适用"与"尚未充分训练"。

§7.3 的判别实验（改变 g 不改善准确率）与这一表述一致，
但同样受限于 1 epoch 与 122 条样本。

## 7. 结论与唯一有依据的方向

### 7.1 已确立的事实

1. **测量对象正确**（D8：max diff = 0）；
2. **交叉注意力读出携带可区分信息**（反事实 Δread = 0.096）；
3. **gate 训练后退化为常数**（sd 0.132 → 0.006）；
4. **信息在更新步骤损失 6 倍**（Δread 0.096 → Δstate 0.0155）。

### 7.2 因果仍有不确定

**不能断言"gate 退化导致任务失败"。** 相关性不足以证明因果。

其他同样可能的解释：

- gate 退化是**结果**而非原因（模型发现记忆无用，于是关掉它）；
- 训练目标（1 epoch）不足以让 gate 学会判别；
- 状态内容本身对任务没用，gate 正确地选择忽略。

**要紧的是**：如果"模型正确地发现记忆无用"，
那问题就**不在 gate，而在任务或状态内容**——这正是评审第 4 条规则。

### 7.3 判别性实验（已执行）：固定 gate 值

**不需要训练**：冻结 checkpoint，把 G2 的 gate 强制设为常数，直接重测。

| g | 0.10 | **0.30** | 0.50 | 0.70 | 0.90 | 0.99 |
|---|---|---|---|---|---|---|
| acc@1 | 0.0820 | **0.1148** | 0.0656 | 0.0984 | 0.0902 | 0.0738 |
| MRR | 0.2654 | 0.2871 | 0.2671 | 0.2716 | 0.2693 | 0.2625 |

测试集 122 条，**随机基线 0.0847，二项标准误 0.0252**。

```
acc@1 spread across g = 0.0492
corr(g, acc@1)        = -0.2182
all values within chance ± 2SE: YES
```

**没有任何单调趋势**：g=0.30 最高、g=0.50 最低、g=0.90 又回升——
形状是**随机波动**，不是"更大的 g 更好"。

**所有 6 个 g 值的准确率全部落在随机 ±2SE 内。**

### 7.4 一次被自己纠正的误判（必须记录）

第一版脚本用"spread > 0.02"作为判据，输出 `gate value MATTERS`。
**这个判据是错的**——spread 只反映最大最小差，
在 n=122 下两三条幸运样本就能把 spread 推到 0.03。

改用"单调性（corr）+ 是否超出随机 ±2SE"后，结论反转为
**gate 值不是瓶颈**。

**记录于此**：若不修正判据，本轮就会得出"改 gate 公式有依据"的错误结论，
而证据其实完全在噪声内。这印证了评审强调的
"相关性只用于发现问题，不足以证明因果"。

### 7.5 最终结论

| 事实 | 强度 |
|---|---|
| 读出携带可区分信息（反事实 Δread = 0.096） | ✅ 直接测量 |
| gate 权重被大幅训练（相对变化 **141%**） | ✅ 直接测量（逐位对比） |
| **但 gate 输出仍是常数 0.52**（sd 0.006） | ✅ 直接测量 |
| 信息在更新步骤损失 6 倍（Δread 0.096 → Δstate 0.0155） | ✅ 直接测量 |
| **gate 值是瓶颈** | ❌ **被判别实验否定**（所有 g 都在随机 ±2SE 内） |

**这里有一个必须说明的张力**：

- gate 确实几乎没被训练，输出是常数；
- **但人为把 g 改成任何值（0.1–0.99），准确率都没有改善**。

**两者合起来说明**：问题不在"gate 取什么值"，
而在于**无论怎么混合新旧状态，状态里都没有对任务有用的信息**。

这直接指向评审的第 4 条规则。

**按评审判定规则的第 4 条：**

> 上述关系都正常，但任务仍失败 → 需要考虑训练目标、状态读取方式
> 或任务本身不适配，而不是继续假定状态更新就是根因。

**本轮属于这种情况。** gate 退化是真实的，
但**强行改变更新幅度并不能提升任务表现**——说明
"更新规则"不是这条链路上的有效杠杆。

## 8. 因此不建议提出 R3

评审要求："最终只选择一个有证据支持的修改方向；若证据不足，就继续诊断，
不强行提出 R3。"

**当前证据不足以支持任何 gate 层面的修改**：

- gate 值对结果无影响（判别实验）；
- 三种 state_update 都坍缩（R1a/R1b）；
- 梯度正常（D2）。

**证据指向的不是"改 gate"，而是更上游的问题**：

1. **训练信号**：1 epoch 不足以让 gate 学会判别（sd 退化可能是"还没学"，不是"学错了"）；
2. **任务适配性**：证据块选择可能不是一个需要跨块记忆的任务——
   每块独立编码后与问题匹配（`concat`/`reset`）就够了；
3. **读出强度**：相邻块读出 novelty 仅 0.0307，本身就很弱。

**下一步建议（未执行）**：先把训练做足（多 epoch），
再重测 gate sd 是否仍退化到 0.006。
若训练充分后 gate 仍不分化，才考虑改 gate 输入；
若 gate 分化了但任务照样失败，则问题确定在任务或读出。

## 9. 局限

1. 仅 1 个 checkpoint、1 epoch，gate 可能只是"还没学会"；
2. 仅 4 篇论文、12 块，样本量小；
3. 相关性基于 n=44，统计功效有限；
4. 反事实只交换了 1 对块，未做系统扫描。

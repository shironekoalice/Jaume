# 元记忆预注册：无查询条件下的写入选择（memory-metamem）

> 状态：**预注册，判定标准冻结后才开始跑评测**
> 日期：2026-10-24
> 依据：`memory-final-report.md` §9.1（唯一未被本文否证的方向）+ `memory-report.md` §8.3（冻结边界）
> 试验台：本机 Intel 核显（torch 2.14.1+xpu），冻结 350m-mlm 骨干

---

## 1. 研究问题

> **在看不到未来查询的前提下，现有表征 + 小判断头能否判断"哪些块值得写入有限容量记忆"？**

这是报告 §9.1 指出的元记忆层（salience / importance 判断）。它与已被否证的状态通道无关：
不训练骨干、不加槽位、不改架构，只在冻结特征上训练一个分类头。
本实验不能因结果好而重启 JM 架构线——它检验的是**写入选择能力是否存在**，不是状态通道。

**标签的代理性质（如实声明）**：正标签 = 该块属于该论文任一问题证据的并集。
这是"未来读者需要的信息"的问答式代理，不是真正的人类重要性标注。结论只能表述为
"对问答有用信息的写入选择"，不能外推为通用重要性判断。

## 2. 数据

- 来源：`data/qasper_blocks/{train,val,test}.jsonl`（论文级隔离，paper_overlap 全 0）。
- 按论文聚合：每篇论文 = 全部块 + 全部问题的证据索引并集 + 问题列表。
- 规模（实测）：581 篇（train 380 / val 84 / test 117，按记录数反推），平均 27.9 块/篇，
  正块率均值 0.087，共约 1.62 万块。
- 块长 ≤128 token（`meta.json: max_block_tokens=128`）。

**划分纪律**：头训练只用 train 论文；一切超参与头的选择（含神经臂之间的选优）只在 val 上做；
test 只跑一次，跑完不再回改。种子 = 1/2/3，仅影响头初始化与训练顺序。

## 3. 臂定义

| 编号 | 臂 | 输入特征 | 说明 |
|---|---|---|---|
| H1 | Linear probe | 冻结 350m-mlm 块嵌入 | 单线性层 |
| H2 | MLP | 同上 | 256 隐层 + ReLU + dropout 0.1 |
| H3 | MLP + trivial | 嵌入 ⊕ 平凡特征 | 检验嵌入在平凡特征之外的增量 |
| B1 | Lexical LR | TF-IDF 1-2 gram（min_df=2, max 50k 维） | 词面基线（对应报告事实 #6：BM25 > 编码器） |
| B2 | Trivial LR | 位置、相对位置、块长、section 分组 one-hot、含数字、is_first/is_last | 平凡特征上限审计 |
| R0 | Random | — | 随机打分参照 |
| U0 | BM25-with-query | 测试查询 + BM25 | **非判定项**：有查询时的选择上限参照 |

协议对齐：B1/B2 与 H1–H3 使用**相同的论文划分、相同的早停数据（val）、相同的正样本
加权与阈值处理**。分类阈值不参与判定（用 AUROC/AUPRC/召回@预算）。

## 4. 指标

- **主指标 M-AUROC**：块级二分类 AUROC，按论文计算后 macro 平均（test 论文）。
- 次指标 M-AUPRC：同协议 AUPRC（类别不平衡 8.7% 下比 AUROC 更敏感）。
- **实用性指标 U-R@25%**：每篇论文按分数保留 top-K 块（K = max(1, ⌊0.25·n⌋)，
  即 25% 写入预算），计算：
  - U1 = 证据并集覆盖率：|kept ∪证据| / |证据|，按论文平均；
  - U2 = 问题级完整保留率：证据集全部落在 kept 中的测试问题占比。
- U0 参照：同预算下 BM25 检索（用测试查询）的 U1/U2——量化"无查询折扣"。

## 5. 预注册判定标准（冻结）

```
M1（主判定）：最佳神经臂（H1/H2/H3 按 val M-AUROC 选一）− B1 的 per-doc AUROC 配对差：
             3/3 种子同号  且  按论文重采样 bootstrap（10,000 次）95% CI 不含 0
M2（实用性）：同协议的 U1(神经最佳) − U1(B1)：3/3 种子同号 且 CI 不含 0
G1（平凡上限审计）：若 B2 的 M-AUROC ≥ 最佳神经臂，则无论 M1/M2 结果如何，
             结论记为"平凡特征已足够，未见神经增量"
G2（纪律）：判定标准与特征集在跑评测前冻结；不追加种子；不换任务；不事后换指标
```

- M1 与 M2 **同时**成立 → 结论："冻结表征存在超越词面特征的写入选择信号"（问题 A 绿灯）。
- M1 成立、M2 不成立 → 结论："排序信号存在但不足以转化为有限预算下的选择收益"（部分）。
- M1 不成立 → 结论："元记忆头未超过词面基线"，与报告事实 #6 同向，问题 A 在此表征上止步。

## 6. 训练与实现配置（冻结）

- 骨干：`350m-mlm`，冻结，eval 模式，max_length 128，L2 归一化嵌入。
- 编码一次后缓存（约 1.62 万块，XPU 推理预计 10–20 分钟），头训练全部在缓存特征上。
- 头优化：AdamW lr 1e-3，wd 1e-4，batch = 32 篇论文的块，最多 50 epoch，
  早停 = val M-AUROC patience 5。**单一学习率，不做 lr 搜索**（防选择面）。
- 损失：BCEWithLogits，pos_weight = train 集 负:正 全局比。
- B1/B2：sklearn LogisticRegression，C ∈ {0.5, 1, 4} 仅在 val 上选一次。
- 统计：配对差 + 按论文 bootstrap；报告每种子原始值。

## 7. 与既有结果的衔接

- 报告事实 #6（编码器语义表示不如 BM25）是在**有查询检索**任务上测的；
  本实验测的是**无查询写入选择**——若 M1 成立，说明词面优势是查询任务特有的，
  神经表征在"前瞻式"判断上有独立价值；若不成立，则进一步确认该表征的边界。
- 本实验通过 ≠ 状态通道复活：任何后续架构实验仍受 §8.3 约束，须重新预注册。

# JM-R 跨块记忆：最终收尾报告

> 日期：2026-10-20
> 状态：**本轮实验结束，结论冻结，不再根据结果调整判定标准**
> 全部产物已归档至 ModelScope `LightNeko/Jaume`

---

## 0. 结论（限定表述）

> **在已测试的块级证据定位任务中，JM-R 的状态通道没有表现出稳定的增量收益；
> 单独使用状态作为块表示还会显著降低性能。**

这不是"JM-R 机制无效"的结论，而是**该机制在已测任务与配置下未观察到收益**。

---

## 1. 证据能支持到什么程度

| 结论 | 支持强度 | 依据 |
|---|---|---|
| `carried` 不适合作为当前任务的单块表示 | **较强** | 5 次运行 **5/5** 低于 `static`，均值 −0.071 |
| `dual` 比只用 `carried` 好 | **较强** | 5 次运行 **5/5** 更好，均值 +0.064 |
| `dual` 优于 `static` | **无证据** | 5 次中 **仅 2 次**为正，均值 −0.007 |
| 状态机制对所有任务都没有价值 | **不能推出** | 仅测试了一种任务类型 |
| 状态含可被下游利用的论文级增量信息 | **尚未证实** | 未做文档级实验 |

### 1.1 统计说明（采纳评审意见）

**5 次运行方向一致 ≠ 统计显著。**

更重要的：**这 5 次不是 5 个独立数据集。**

| 划分 | 种子 | 运行数 |
|---|---|---|
| split0 | 0, 1, 2 | **3 次** |
| split1 | 0 | 1 次 |
| split2 | 0 | 1 次 |

**split0 占了 3/5**，因此不能把 5 次规模当作独立样本估计泛化能力。
跨划分的独立证据只有 **3 个划分**。

### 1.2 `dual − static = −0.007` 的正确表述

**错误表述**：状态一定没有增量信息。

**正确表述**：

> 在当前模型、训练配置、任务与样本规模下，
> **没有观察到 `dual` 相对 `static` 的稳定增益**
> （5 次中 2 次为正，均值 −0.007，范围 −0.025 ~ +0.019）。

## 2. 已建立的确定知识

这些是通过直接测量得到的，不依赖对机制的解读：

| # | 事实 | 测量方式 |
|---|---|---|
| 1 | 350M 编码器**零训练就有块级信号** | cos(gold)−cos(other)=+0.021；gold 平均排名 3.42（随机 6.0）；27.5% 排第一 |
| 2 | **全量微调会破坏该信号** | lr=1e-5/3e-5/1e-4 三个设置，训练后分离度均降至 ≤+0.0044 |
| 3 | 冻结骨干 + 525K 参数头，170 秒达 0.30 F1 | 直接测量 |
| 4 | 状态作为块表示劣于块自身向量 | 5/5 一致，−0.071 |
| 5 | 状态顺序相关（错状态更差） | `carried` > `shuffled`，+0.032，5/5 |
| 6 | **编码器语义表示不如 BM25** | static 0.28–0.31 vs BM25 0.322（零训练） |

第 6 条值得单独强调：**在这个任务上，字面检索强于 350M 语义编码。**

## 3. 解释假说（未经验证）

以下是对观察结果的**假说**，实验本身**没有**证明它：

> **假说**：状态是累积和 `state_i = state_0 + Σ read(b_j)`，
> 读到第 i 块时混入了前面所有块的内容，稀释了当前块的辨识度；
> 因此不能胜任"单块表示"的角色。

**为何这只是假说**：

- 实验测量的是**任务表现**，不是状态内部编码了什么；
- 未做线性探针检查 `state_i` 对块 i 内容的可辨识性；
- "累积和"是读代码得到的事实，但"稀释导致任务退化"这一因果链未验证。

## 4. 已修复的混淆因素（本轮的主要工作量）

这些修复本身构成了方法学上的净收益：

| 混淆 | 问题 | 修复 |
|---|---|---|
| 筛选泄漏 | 用 BM25 在测试集上的表现筛选样本，使基线低估 2.2 倍（0.140 vs 真实 0.302） | 移除该筛选，重建 `qasper_comp_clean` |
| 对照不公平 | 原 `concat` 是两嵌入相加，缺少第二步前向 | 改为各块独立编码后聚合 |
| 代码恒等 | 非循环臂的 `reset`/`carried` 执行同一段代码，25 个格子不含证据 | 打桩验证并标注 |
| 评测漏投影 | 评测返回投影前向量，训练集 0.656 的模型被测成 0.16 | 补 `projection` |
| 训练目标病态 | 单标签 CE vs 集合 F1；55% 正确块被推离 | 多标签 BCE |
| 全量微调破坏 | 三个学习率均破坏预训练信号 | 改用冻结骨干 |
| 统计表述 | "27 倍标准差"混用了不同统计量 | 改配对差值 + bootstrap CI |

## 5. 剩余限制（如实记录）

1. **测试集规模小**：168–179 条/划分；
2. **跨划分独立证据只有 3 个**，split0 有 3 个种子；
3. **只测了一种任务**（块级证据定位）；
4. **只测了一个 base**（`350m-mlm`），未测其他预训练阶段；
5. **状态通道的机制未被直接诊断**（未做探针检查 state 内容）；
6. **BM25 未与模型做同样的训练**，两者不是严格同条件比较。

## 7. 如果日后继续：唯一保留的方向

**文档级预测的增量价值验证。**

必须回答的一个问题：

> 在相同训练与评测条件下，加入跨块状态，
> 能否让**文档级**预测优于不传递状态的模型？

实验最小配置：

| 项 | 要求 |
|---|---|
| 对照 | `static`（不传状态）/ `carried`（用最终状态做文档级预测） |
| 可选 | `shuffled`（检查顺序是否重要） |
| 数据 | 按文档/论文隔离 train/val/test |
| 事前 | 固定主指标、判定标准、计算预算 |

**若 `carried` 不显著优于 `static`，则结束该方向，不再换任务寻找正结果。**

**前置检查**（必须先做，成本低）：

1. 是否已有文档级任务与可靠标签？
2. 能否复用现有数据？
3. **状态是否真的参与最终预测**（避免再次出现"输出路径不使用状态"的问题）？

**若必须重建数据、训练管线与评测体系，则暂缓。**

---

## 8. 明令不做的事

- ❌ 不再扩展架构（不加槽位、不加读出层）
- ❌ 不再做参数搜索
- ❌ 不再为了寻找正结果而更换任务
- ❌ 不根据结果调整判定标准

**理由**：现有结果没有显示状态通道具有增量收益，
此时增加复杂度只会让归因更困难。
